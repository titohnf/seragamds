# Badge

- Kode: `Badge` (`src/components`)
- Spesifikasi visual: [badge.md](../../components/badge.md)

> **Status: dari panduan Seragam** (seragam.belajar.id), disesuaikan ke props komponen di repo ini.

## Nada
| `tone` | Arti | Kapan dipakai |
|---|---|---|
| `green` | Sukses | Aktif, berhasil, selesai |
| `amber` | Peringatan | Perlu perhatian, mendekati batas waktu |
| `red` | Kritis | Galat, gagal, perlu tindakan segera |
| `blue` | Informasi | Informasi netral |
| `gray` (default) | Netral | Status bawaan, draf, tidak aktif |

## Panduan
- Satu badge menyatakan satu status. Teks pendek, 1–2 kata.
- Jangan mengandalkan warna saja: teks badge harus menyampaikan statusnya.
