# Expander

- Kode: `Expander` (`src/components`)
- Spesifikasi visual: [expander.md](../../components/expander.md)

> **Status: dari panduan Seragam** (seragam.belajar.id), disesuaikan ke props komponen di repo ini.

Props: `expanded`, `onToggle`, `inverted`, `expandLabel` (default "Selengkapnya"), `collapseLabel` (default "Sembunyikan").

## Panduan
- Tampilkan sebagian isi dulu sebagai konteks, lalu letakkan Expander.
- Rata kiri mengikuti grid paragraf.
- Pakai untuk mengurangi kepadatan halaman.

## Penulisan
Kata buka: "Selengkapnya" atau "Tampilkan semua". Kata tutup: "Tutup" atau "Sembunyikan". Konsisten di seluruh platform.
