# Elevasi dan radius

## Elevasi

Kelas: `shadow-sd-00` … `shadow-sd-08`. Pakai elevasi 01 untuk kartu, 06 untuk modal.

| Level | Kegunaan | CSS |

| `01` | Use for panels, cards subtle | `0px 1px 3px 0px rgba(0,0,0,0.10), 0px 2px 1px -1px rgba(0,0,0,0.02), 0px 1px 1px 0px rgba(0,0,0,0.08)` |
