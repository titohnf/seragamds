# Palet warna ilustrasi

Sumber: seragam.belajar.id/palet-warna-ilustrasi. Untuk ilustrator; selaras dengan gaya ilustrasi Seragam. Setiap warna punya **5 turunan dari terang (10) ke gelap (50)** yang berbeda *value* dan *hue* supaya terbentuk cahaya dan bayangan. Satu ilustrasi memakai tiga turunan: dasar (base), bayangan (shadow), dan garis detail/cahaya.

> **Status: nilai disampel dari gambar resmi.** Halaman sumber menampilkan palet hanya sebagai gambar, jadi heks di bawah diambil dengan sampling piksel (`skill-illustration/references/palette.json`) dan perlu dicek terhadap file Figma *Galeri Ilustrasi*. Palet ini **terpisah dari token UI** ([warna](warna.md)): jangan dipakai untuk komponen, dan jangan memakai warna token UI di ilustrasi.
