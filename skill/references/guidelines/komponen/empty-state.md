# Empty State

- Kode: `EmptyState` (`src/components`)
- Spesifikasi visual: [empty-state.md](../../components/empty-state.md)

> **Status: dari panduan Seragam** (seragam.belajar.id), disesuaikan ke props komponen di repo ini.

Props: `title`, `description`, `artwork`, `action`.

| Jenis | Kapan dipakai |
|---|---|
| Tanpa aksi | Hanya memberi informasi |
| Dengan aksi (`action`) | Informasi + tombol langkah berikutnya |

## Panduan
- **Selalu** jelaskan mengapa kosong.
- **Selalu** arahkan langkah berikutnya.
- Jangan hanya menulis "Tidak ada data".
- Boleh tampil layar penuh, di dalam tabel, atau di dalam kartu.
- Lebar: mobile 235–296px atau penuh; desktop 295–520px.

## Penulisan
Judul Title Case ("Belum Ada Data"). Deskripsi sentence case dan mengarahkan tindakan.
