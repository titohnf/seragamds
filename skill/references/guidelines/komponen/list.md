# List

- Kode: `List, ListItem` (`src/components`)
- Spesifikasi visual: [list.md](../../components/list.md)

> **Status: dari panduan Seragam** (seragam.belajar.id), disesuaikan ke props komponen di repo ini.

Props `ListItem`: `label`, `description`, `artwork`, `end`, `onClick`.

## List vs Card
- List: data berbasis teks, gambar hanya pelengkap, hemat ruang.
- [Card](card.md): visual/gambar menjadi fokus utama.

## Panduan
- Cocok untuk navigasi sederhana (ketuk lalu buka halaman detail).
- Jangan pakai bila data mengutamakan visual.
- Mobile: satu kolom.

## Penulisan
Judul maksimal 2–3 kata. Sentence case.
