# Breadcrumb

- Kode: `Breadcrumb` (`src/components`)
- Spesifikasi visual: [breadcrumb.md](../../components/breadcrumb.md)

> **Status: dari panduan Seragam** (seragam.belajar.id), disesuaikan ke props komponen di repo ini.

Props: `items` (`{ label, href?, onClick? }`). Item terakhir adalah halaman saat ini.

## Panduan
- Pakai bila hierarki halaman dalam.
- Letakkan di kiri atas halaman, di bawah navigasi utama.
- Mobile: tampilkan maksimal 2–3 level terakhir.
- Jika urutan terlalu panjang, ringkas: "Beranda > … > Halaman ini".

## Penulisan
Maksimal 3 kata per level. Sentence case. Tanpa titik di akhir.
