# Seragam Design System

Sumber kebenaran (folder `references/` di samping berkas ini): `references/seragam.tokens.json` dan `references/seragam.css` (token), `references/components-spec/<nama>.md` (spesifikasi tiap komponen dari Figma), `references/react-src/` (kode komponen React siap salin), `references/foundations/` (warna, tipografi, elevasi, spacing), `references/guidelines/` (panduan penggunaan per komponen di `komponen/<nama>.md`, panduan penulisan `penulisan.md`, prinsip desain `prinsip-desain.md`, ilustrasi `ilustrasi.md`, pemetaan nama `pemetaan-nama.md`), `references/extensions.md` dan `references/DECISIONS.md`.

Untuk proyek baru: salin `references/seragam.css` ke proyek dan impor setelah `@import "tailwindcss"`; salin komponen yang dibutuhkan dari `references/react-src/components/` beserta `tokens.ts`. Di proyek yang memasang paket `seragam-design-system`, impor dari paket itu dan tambahkan `@source "../node_modules/seragam-design-system/src";` di CSS agar Tailwind memindai kelasnya.

## Aturan
1. **Jangan menulis hex langsung.** Pakai kelas token: `text-sd-gray-90` (teks), `text-sd-gray-60` (teks sekunder), `text-sd-blue-70` (aksi/tautan), `border-sd-gray-50`, `bg-sd-gray-0` (latar halaman), `bg-sd-blue-5` (terpilih).
2. **Tipografi** Inter, **satu komponen dua skala**: Mobile di layar kecil, Desktop di layar lebar (dipilih atribut `data-sd-platform`: `auto` bawaan = Desktop mulai 1024px, `desktop`, `mobile`; atau komponen `Platform`). Peran: body 15/22 ↔ 16/24, body-small 13/20 ↔ 14/20, action 15/22 ↔ 16/24 semibold, subheading 13/16 ↔ 14/16, heading-small 16/22 ↔ 17/22, heading-medium 18/24 ↔ 19/24, heading-large 22/28, display-small 24/28, helper 12/16. **Jangan menulis ukuran huruf angka** (`fontSize: 15`, `text-[15px]`); pakai `style={typo.body}` (`src/tokens.ts`) atau kelas `sd-t-body`, `sd-t-action`, dst. Tinggi kontrol dihitung dari tinggi baris (`calc(var(--sd-text-body-line) + 24px)`). Hanya berat 400 dan 600. Jangan ukuran di luar skala.
3. **Radius**: kontrol 4px, kartu 8px, badge pill. **Bayangan**: Elevation 01 kartu, 06 modal.
4. **Komponen**: sebelum membuat komponen, baca `references/components-spec/<nama>.md` dan ikuti ukuran, padding, gap, dan token warnanya. Pakai komponen di `src/` bila ada (Carousel, Footer, Spinner, Skeleton, Tabs, Table, Panel, DescriptionList, PageHeader, ProcessSteps, VerticalNavigation, Button, Badge, Banner, Chip, Checkbox, Radio, Switch, TextField, TextArea, Modal, Toast, Select, Tooltip, Breadcrumb, Pagination, Stepper, Accordion, Avatar, Card, Link, ProgressBar, EmptyState, List, Separator, SearchBar, Popover, Slider, Expander, Rating, HeaderBar, NavigationBar, BottomSheet).
5. Hex lama di Figma (`#0B5FEF`, `#65686C`, `#2F3031`) = token baru (`blue-70`, `gray-60`, `gray-90`); selalu pakai token baru.
6. Pastikan kontras teks minimal WCAG AA (teks sekunder pakai `gray-60`, bukan lebih pucat).
7. Button: pakai `variant` ultimate (aksi utama, biru), primary (hitam), secondary (outline), quiet (teks), destructive (merah solid), atau `destructive-secondary` (outline merah, ekstensi untuk Tolak/Hapus). Jangan menulis kelas tombol sendiri.
8. Tabel: pakai komponen `Table` (header 13/16 semibold kapital, sel 15/22 sudah bawaan); jangan menulis `<table>` dengan kelas sendiri. Kolom Aksi: ≤2 tombol tampil langsung, >2 masuk menu ⋮.
9. **Panduan penggunaan**: sebelum memakai komponen, baca `references/guidelines/komponen/<nama>.md` (kapan dipakai, do & don't). **Tampilan DAN perilaku harus sesuai panduan**: periksa bagian Perilaku (keyboard, state, penutupan, durasi), Responsif, dan Penulisan, lalu pastikan hasil akhirnya memenuhinya. Bila panduan menyebut sesuatu "belum ada di kode", beri tahu pengguna dan tandai penyimpangannya; jangan diam-diam mengarang. Halaman bertanda *draf* belum resmi; ikuti sebagai saran dan tandai bila Anda menyimpang.
10. **Penulisan teks UI**: baca `references/guidelines/penulisan.md` sebelum menulis teks. Semua teks Bahasa Indonesia; tombol: kata kerja, sentence case, maks 3 kata; galat: masalah + solusi; empty state: judul Title Case, jelaskan alasan kosong dan arahkan langkah berikutnya; tidak ada "Lorem ipsum".
11. **Nama komponen**: gunakan nama kode (mis. `TextField`, `Modal`, `BottomSheet`). Nama `@wartek-id` (`Input`, `Dialog`, `Sheet`, `Navbar`) tidak ada di sini; lihat `references/guidelines/pemetaan-nama.md`.
12. **Kartu berbagian dan data berpasangan**: pakai `Panel` (header berjudul + garis pemisah) dan `DescriptionList` (label di atas nilai). Jangan menulis `<section>` ber-border atau pasangan label–nilai dengan ukuran font manual. Keduanya ekstensi di luar Figma (lihat `references/extensions.md`).
13. **Ilustrasi**: panduan di `references/guidelines/ilustrasi.md`, palet di `references/foundations/palet-ilustrasi.md`. Untuk membuat atau mencari ilustrasi (Spot, Empty State, Hero), gunakan skill `seragam-illustration`. Jangan memakai warna token UI di ilustrasi.
